Power Gym - Windows installer
=============================

1. Extract this whole folder (keep Install.bat, install.ps1 and the "app" folder together).
2. Double-click Install.bat. A window with a progress bar opens.
   - The first install downloads the app runtime once (about 115 MB), so it needs internet.
   - Shortcuts are added to the Desktop and Start Menu.
   - The app appears in Settings > Apps, so it can be uninstalled like any program.
3. Your data is stored in: Documents\Power Gym
   (power-gym-data.json, automatic backups, and saved reports).
4. To remove the program: Settings > Apps > Power Gym > Uninstall (your data is kept).
